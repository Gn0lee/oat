# 목적별 장부 iPhone 흐름 모형

질문: 전체 장부와 특정 장부 전환, 기록 입력·재분류, 장부 관리를 어디서 시작하면 가장 명확한가?

모형 규칙: 장부 하나가 공용 또는 개인이다. 그 안의 모든 기록은 장부의 공개 범위를 따르며, 다른 공개 범위의 장부로 옮기면 공개 대상도 바뀐다. 개인 장부의 이름과 기록은 만든 사람에게만 보인다. 기록별 공개 범위 선택은 없다.

- A: 가계부 허브 상단에서 장부를 고르고 기능으로 이동
- B: 장부 서가에서 장부를 먼저 고른 뒤 달력·검색·분석으로 이동
- C: A의 전체 요약과 B의 장부별 탐색을 합친 혼합안. 첫 화면 아래에서 전체 장부의 달력·검색·분석으로 바로 이동하고, 각 화면에서 장부를 바꾼다. 달력은 한 주만 보이다가 펼칠 수 있다.

`pnpm dev` 또는 Vercel preview 배포에서 `/ledger?prototype=books&variant=A`로 시작한다. production 배포에서는 열리지 않으며 모든 변경은 메모리에만 남는다.
설치형 PWA에서는 **가계부 → 목적별 장부 시안 비교**로 진입하고, 모형 상단의 **기존 가계부로 돌아가기**로 나온다.

사용자 선택: **C의 화면 흐름.** 전체 요약과 목적별 장부 목록을 함께 두고, 전체 장부의 달력·검색·분석으로 바로 들어가며 각 화면에서 장부를 바꾼다. iPhone에서 주간 달력과 이동 흐름을 확인했고, 시각적 완성도는 제품 구현에서 다듬는다. A의 전역 선택기와 B의 큰 장부 카드 목록은 채택하지 않는다.
