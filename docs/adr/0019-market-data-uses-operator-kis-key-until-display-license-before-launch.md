# 시세는 초대제 동안 운영자의 KIS 키로 받고, 정식 출시 전에 표시 라이선스가 있는 공급원으로 바꾼다

시세는 "받을 권리"와 "남에게 보여줄 권리"가 따로 팔린다. KIS 고객 약관(제5조 ③)은 시세를 "개인의 업무에 한하여" 쓰고 "제3자에게 제공해서는 아니 된다"고 정한다. KRX Open API도 비상업·제3자 제공 금지이고, data.go.kr 국내 시세는 비상업·출처표시 조건이다. 미국은 표시가 허용된 플랜이 월 $250(Tiingo 재배포 등급, 조건 확인 필요)~$2,499다. 공개 서비스에 맞는 무료·합법 경로는 없다.

그래서 단계별로 간다. **초대제(무료·비상업) 동안**은 지금 운영 중인 oat처럼 운영자 한 사람의 KIS 앱키로 종목 마스터·장중 현재가·일별 종가·배당 일정을 받는다. 약관과 부딪치는 회색지대라는 것을 알고 받아들인다. 국내 종가 백필은 KIS가 실패할 때 data.go.kr로 받고 출처를 표시한다. **정식 출시 전**에는 표시 라이선스가 있는 공급원으로 바꾸는 것을 출시 준비의 조건으로 둔다. 유료화를 시작하면 비상업 조건인 data.go.kr도 바꾼다.

교체가 테이블·화면을 흔들지 않도록, worker는 데이터 종류별 **시세 공급원** 인터페이스만 부르고 DB에는 우리 모양만 저장한다. 우리 코드가 정본이고 공급원 표기 대응은 어댑터가 한다. 종가는 원주가만 저장한다. 배당 이벤트의 자연키는 공급원 번호가 아니라 `(종목, 배당락일, 일반/특별)`이다. 빈 값으로 기존 값(미국 종목 한글 이름 등)을 덮지 않는다. 유형 대응은 어댑터 테스트로 지키고, 모든 행에 출처를 남긴다.

## Considered Options

- **처음부터 표시 라이선스 계약**: 가장 깨끗하다. 하지만 가구 몇 개에 월 수십만 원 이상이고, 국내 계약은 법인·거래소 정보이용계약이 필요해서 택하지 않았다.
- **가구마다 자기 KIS 앱키를 넣게 함**: 각자 "개인의 업무"가 된다. 하지만 한국투자증권 계좌가 필수가 되고, 남의 앱키·시크릿을 서버에 보관해야 하며(약관 제5조 ②의 대여·위임 금지와도 애매하다), 온보딩이 무거워서 택하지 않았다.
- **현재가·평가액을 보여주지 않고 원가만**: 라이선스 문제는 사라진다. 하지만 투자 수익률과 월별 자산 추이 질문(ADR 0016)을 포기해야 해서 택하지 않았다.
- **초대제 동안 국내는 data.go.kr 종가만, 미국은 시세 없음**: 약관상 가장 안전하다. 하지만 장중 현재가가 없고 미국 종목 평가가 통째로 빠져서 택하지 않았다.
- **시세 조회 MCP**: MCP는 AI 클라이언트가 우리 서버를 쓰는 통로이고, worker가 정해진 시각에 부르는 공급원이 아니어서 택하지 않았다.
- **수정주가 저장**: 차트 도구에서 흔하다. 하지만 기록의 수량은 분할 전후의 실제 수량이라 "수량 × 종가"가 틀리고, 다시 받을 때 과거 값이 바뀌어서 택하지 않았다.

## Consequences

- 정식 출시 준비에 "시세 표시 라이선스 계약"이 조건으로 들어간다. 계약 전에는 정식 출시하지 않는다.
- KIS 계좌와 앱키는 운영자 한 사람의 것이고 시크릿은 서버에만 둔다. 접근 토큰(1일 유효, 재발급 1분 1회)은 Postgres 전역 운영 행에 두고 worker만 갱신한다.
- 초대제 단계에서 미국 폐지 종목의 과거 종가는 받을 곳이 없다. 그 종목은 해당 달 평가에서 빠지고 "시세 없음"으로 보인다.
- 티커 변경(FB → META)은 자동으로 잇지 않는다. 보유 종목이 마스터에서 사라지면 운영자에게 알리고, 운영자가 같은 행의 코드를 바꾸며 옛 코드는 코드 이력에 남긴다. ISIN은 받을 수 있을 때 칸으로 저장해 두고, ISIN을 주는 공급원으로 바꾸면 자동 연결로 바꾼다.

→ 정식 출시 공급원은 ADR 0038에서 구체화했다: 종가, 국내 data.go.kr(무료인 동안), 미국은 서면 허락을 받은 공급원.
