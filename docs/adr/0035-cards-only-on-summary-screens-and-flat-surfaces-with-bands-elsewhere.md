# 카드는 요약 화면에만 쓰고, 나머지 화면은 흰 평면과 회색 띠로 나눈다

카드(회색 바탕 위 둥근 흰 상자)는 **요약 화면(홈·자산 탭)**에서 주제 단위로만 쓴다. 기록 목록·상세·분석·투자·지갑·설정·입력 확인은 흰 평면이고, 주제가 크게 바뀔 때만 높이 16의 회색 띠(바탕색)로 나눈다. 띠 아래에는 섹션 제목을 두고, 평면 화면의 상단 바는 회색 바탕 위에 둔다. 줄 사이 선은 기본으로 긋지 않는다.

요약 화면에서 카드가 분산되어 보이는 문제는 카드 수가 아니라 위계로 푼다. 큰 숫자는 맨 위 카드에만 두고, 다른 카드는 17pt 줄로 가볍게 하며, 한 줄로 끝나는 정보("눈에 띄는 것")는 카드 없이 바탕 위에 둔다.

기존 oat는 카드를 너무 많이 써서 어색했다. 토스·카카오뱅크·현대카드 홈은 모두 회색 바탕 위에 카드를 연달아 쓰고(사용자 캡처), 토스 통장 화면은 흰 평면과 16 띠(TDS `Border height16`)를 쓴다. 같은 종류가 반복되는 내용은 카드가 아니라 목록이다(Material, NN/g).

## Considered Options

- **어디나 카드**: 긴 목록이 날짜마다 끊기고, 여백이 두 번 들어가 SE에서 좁다.
- **어디나 평면**: 홈의 따로 켜고 끄는 주제가 경계 없이 섞인다.
- **홈은 숫자 카드 하나 + 아래는 꽉 찬 흰 면 하나**: 공통 영역 원칙으로는 분산을 줄이지만, 회색 바탕 일부와 흰 면이 위아래로 갈린 모양이 흔한 패턴이 아니고 어색했다.
- **흰 바탕 + 숫자 카드만 리넨 색조**: 근거 없이 바탕을 바꾸는 안이었다.
- **바탕을 토스 푸른 회색(`#F2F4F6`)이나 Pine 회색으로**: 나란히 비교했고, 어색함의 원인은 색이 아니라 구조(흰 상단 바, 잦은 띠, 제목 없는 띠)였다. 귀리 회색 `#F4F5F3`을 유지한다.

## Consequences

- 카드 치수는 토스 홈 실측(바깥 12, 안 20, 사이 12, 모서리 20)이라 카드 화면의 글자 시작선(32)과 평면 화면(24)이 다르다. 맞추지 않는다.
- "눈에 띄는 것"이 홈 카드에서 숫자 카드 아래 한 줄로 바뀐다(통계 화면 구성 4.1).
- 그림자를 쓰지 않고 면은 색 차이로 나눈다.
