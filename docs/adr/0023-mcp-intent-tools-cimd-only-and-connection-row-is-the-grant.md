# MCP는 의도별 툴만 내주고, 클라이언트는 CIMD로만 받으며, 권한과 동의의 정본은 우리 연결 행이다

MCP로 AI 클라이언트에 내주는 쓰기는 **기록**(생성·수정·삭제)뿐이고, 툴은 앱 입력 화면과 같은 의도 단위(지출 추가, 이체, 매매, 돌려받은 돈, 예정 확정)다. 다리를 직접 적는 범용 쓰기와 뼈대(지갑·카테고리·장부·정기 규칙) 쓰기, 잔액 맞춤, 청구서 확정은 내주지 않는다. 다리·줄 불변식을 AI가 맞추게 하면 실수가 잦고, 뼈대가 틀리면 기록 수백 건의 잔액과 통계가 함께 흔들리기 때문이다.

AI 클라이언트는 **Client ID Metadata Document(CIMD)로만** 등록받고 동적 등록(DCR)은 켜지 않는다. 초대제 동안은 확인한 클라이언트의 문서 주소만 허용 목록으로 받는다(Claude, ChatGPT·Codex, Hermes). CIMD는 클라이언트 신원을 그 회사 도메인으로 확인할 수 있고, 현행 MCP 스펙(2026-07-28)이 권장하며 DCR은 하위 호환용이 됐다. Better Auth의 기본 도메인 검사에서 `client_uri`는 뺀다. 표시용 링크라 동의 화면에 쓰지 않고, 기본값은 실제로 Hermes를 거절했다.

**AI 연결의 권한(조회만 / 조회·쓰기)과 동의의 정본은 우리 DB의 `ai_connections` 행이다.** OAuth 스코프는 하나만 쓰고, Better Auth의 동의 기록은 남기지 않는다. 권한을 토큰 스코프에 새기면 바꿀 때마다 다시 연결해야 하고, `/mcp`는 어차피 요청마다 DB에서 연결을 확인하므로(ADR 0022) 그 행에서 권한을 읽으면 바로 반영된다. PoC에서 Better Auth 동의 기록을 남겼더니 다음 연결 때 우리 동의 화면을 건너뛰었다. 연결 행은 사용자가 아니라 가구 멤버 행에 묶어서, 가구를 나가면 조회가 바로 0행이 된다.

쓰기 안전장치는 클라이언트 행동에 기대지 않는다. MCP 기록 생성은 볼 수 있는 장부 안에서 같은 지갑·날짜·금액이 있으면 저장하지 않고 `possible_duplicate`로 돌려주고, 사용자 확인 뒤 `allow_duplicate`로만 저장한다. AI는 재시도마다 같은 중복 방지 키를 쓴다는 보장이 없고, 앱으로 적은 결제를 카드 문자로 또 넣는 경우는 키로 막을 수 없다. 되돌리기는 감사 기록(연결 ID 포함)으로 앱에서 건별로 한다. PoC에서 Claude는 `destructiveHint`가 붙은 삭제 툴을 묻지 않고 실행했다.

## Considered Options

- **범용 `create_record(다리, 줄)` 툴**: 툴 수가 적고 모든 기록 종류를 한 번에 연다. 부호·합계 실수를 AI에게 떠넘기고, 앱과 다른 검증 경로가 생겨서 택하지 않았다.
- **DCR도 켜기**: Cursor·Gemini CLI처럼 DCR만 지원하는 클라이언트도 붙는다. 누구나 아무 이름으로 클라이언트를 만드는 열린 입구라서 쓰레기 등록과 가짜 이름 피싱을 따로 막아야 한다. 꼭 필요한 앱은 운영자가 사전 등록한다.
- **조회·쓰기를 OAuth 스코프 두 개로**: 표준적이다. 권한을 바꾸려면 다시 연결해야 하고, 토큰과 DB에 권한이 두 군데 생긴다.
- **조회만 연결에서 쓰기 툴을 목록에서 숨기기**: 깔끔해 보인다. PoC에서 Claude가 예전 목록으로 부르고 "툴 없음"을 받아 "일시적인 연결 문제"라고 안내했다. 목록에 두고 이유를 담아 거절한다.
- **동의 때 장부를 하나씩 고르기**: 세밀하다. 동의·해지 화면, 새 장부 처리, AI가 본 통계와 앱 통계의 차이가 모두 복잡해져서 요구가 생기면 더한다.

## Consequences

- 로그인·동의 화면은 API 서버가 HTML 두 장으로 낸다(웹 앱은 여전히 없다). 동의에 쓴 브라우저 로그인은 코드→토큰 교환 직후 지운다. 동의 직후에 지우면 토큰 교환이 실패한다.
- 앱에 설정 → AI 연결(목록, 권한 바꾸기, AI가 바꾼 기록과 되돌리기, 해지)이 필요하다.
- `audit_log`에 `ai_connection_id`를 더한다.
- 허용 목록 밖의 AI 앱은 연결할 수 없다. 새 앱은 CIMD 지원을 확인하고 목록에 한 줄 더한다.
- 툴은 도메인 서비스 위의 얇은 입구라서, 나중에 앱 안 AI 채팅을 만들면 같은 툴을 재사용한다.
