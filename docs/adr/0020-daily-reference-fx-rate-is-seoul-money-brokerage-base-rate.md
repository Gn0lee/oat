# 그날 기준환율은 기록 날짜의 서울외국환중개 매매기준율이다

외화가 든 기록의 원화 값을 계산하는 **기준환율**을 "기록 날짜에 마지막으로 고시된 환율"에서 "**기록 날짜의 서울외국환중개 매매기준율**(그날 값이 없으면 직전 영업일 값)"로 바꾼다. 출처는 한국은행 ECOS `731Y001`(원/미국달러)이고, 수출입은행 API의 `kftc_deal_bas_r`로 매일 교차 검증한다. 값은 지금처럼 기록에 함께 저장하고 사용자가 증권사 적용 환율로 고칠 수 있다(물리 DB 스키마 4.3).

"그날 마지막 고시"는 하루에 여러 번 고치는 은행 고시에서만 뜻이 있는데, 은행 고시는 공식 API가 없고 스크래핑밖에 없다. 서울외국환중개 매매기준율은 전 영업일 거래의 가중평균으로 영업일 아침에 한 번 고시되고, 은행들이 그날 1회차 고시로 쓰는 값이다. ECOS가 1964년부터 무료로 주므로 전환에 필요한 백필도 몇 번의 호출로 끝난다.

같은 정의를 해외 결제의 원화 추정에도 쓴다. 그래서 USD뿐 아니라 ECOS `731Y001`이 주는 주요 통화(엔·유로·위안 등)도 받는다([모바일 입력 UX 원칙](../design/mobile-input.md) 2.2, 2026-11-21 추가). USD 외 통화의 ECOS 값은 USD 매매기준율에서 나온 재정환율이고, 1단위당으로 정규화해 저장한다.

## Considered Options

- **은행(하나은행) 마지막 회차를 스크래핑**: 옛 정의를 그대로 지킨다. 하지만 허용 근거가 없고 사이트가 바뀌면 깨져서 택하지 않았다.
- **수출입은행 매매기준율(영업일 11시 전후)**: 은행 고시에 조금 더 가깝다. 하지만 정의가 덜 공식적이고 과거 조회 범위가 확인되지 않아 보조로만 쓴다.
- **국제 중간값(ExchangeRate-API, Frankfurter 등)**: 하루 중에도 갱신된다. 하지만 국내 고시와 몇 원씩 다르고, ExchangeRate-API 무료 플랜에는 이력이 없어서 택하지 않았다.

## Consequences

- "최신 환율"(통계 A1의 평가 시점 환율)도 하루 한 번 바뀐다. 기존 ExchangeRate-API 2시간 동기화는 새 서버에 가져가지 않는다.
- 전환 전에 `fx_rates`를 2025-01-01부터 채운다.
- 매매기준율 산정을 시간가중평균으로 바꾸는 외국환거래규정 개정이 2027-01-01 시행 예정이다. 정의는 "그날의 매매기준율"로 그대로 두고, 출처·고시일로 구분하며 과거 값은 다시 계산하지 않는다.
- ECOS 이용약관의 상업 이용·출처 표시 조건은 정식 출시 전에 원문으로 확인한다.

→ ECOS·수출입은행 약관 확인은 [정식 출시 조건 목록](../design/launch-conditions.md) 3.1에 넣었다.
