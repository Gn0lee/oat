# 정식 출시 시세는 종가이고, 표시 권리는 서면으로 확보한다

ADR 0019의 "정식 출시 전 표시 라이선스 공급원으로 교체"를 구체화한다. **정식 출시 조건은 국내·미국 보유 종목을 모두 종가로 평가할 수 있고, 그 종가를 앱 사용자에게 보여줄 권리를 서면으로 확보한 것이다.** 장중 시세는 조건이 아니다. 월별 자산 추이와 평가액은 종가로 계산되고, 실시간·지연 시세는 계약이 무겁다(코스콤 실시간 기본료는 2014년 기준 유가증권 월 150만 원 + 1인당 월 2천 원).

- **국내는 data.go.kr**(금융위원회 주식시세·증권상품시세·KRX상장종목정보, 예탁원 배당정보)이다. 공공누리 4·2유형(출처표시·비상업)이라 **무료·광고 없음**인 동안만 쓴다. 다음 영업일 13시 이후에 올라와 평가가 하루 늦는 것을 받아들인다. 비상업·변경금지 해석을 제공기관에 서면으로 확인한다. 유료화나 광고를 시작하면 바꾼다.
- **미국은 서면 허락을 받은 공급원**이다. 무료로 앱 사용자 표시를 허락하는 미국 종가 출처는 없다(무료 API는 모두 개인·내부용). Alpha Vantage에 무료 허락을 요청하고, 안 되면 marketstack Basic(월 $9.99)의 표시 권한을 확인한다. 둘 다 안 되면 그때 사용자 직접 입력과 유료 공급원 중에서 다시 정한다.
- **긁어오지 않는다.** 가격 숫자에는 저작권이 없지만 API 약관, 데이터베이스 보호(저작권법 93조), 부정경쟁방지법 데이터 조항, Apple 5.2.2(제3자 콘텐츠 권리 증빙)에 걸린다. 받은 서면 답이 심사 증빙이다.
- **AI 연결은 원시 시세를 내주지 않는다.** 종목별 현재가·종가 목록 툴을 두지 않고 평가액만 내준다. 공급원 약관(코스콤 옵션 3 등)이 API 재배포를 금지하는 데 대비한다.
- 초대제의 KIS 장중 현재가는 정식 출시 전에 끈다.

## Considered Options

- **미국 시세 없이 출시**("시세 없음"): 비용은 없지만 미국 주식을 가진 가구의 총자산이 틀려 핵심 가치(가족 자산을 한눈에)가 깨진다.
- **유료 공급원 계약**(Twelve Data Venture 월 $124~, Tiingo 재배포 월 $250, 코스콤 옵션 3 견적): 확실하지만 무료 앱의 고정비가 크다. 문의가 모두 실패할 때의 후보로 남긴다.
- **사용자가 가격을 직접 입력**: 돈은 들지 않지만 숫자가 쉽게 낡고 입력이 늘어 보조 수단에 그친다.
- **국내도 유료 공급원으로 당일 종가**: 하루 지연이 없지만 비용·계약 부담이 크다.

## Consequences

- 국내 평가는 "M/D 종가 기준"이고 하루 늦다. 통계 화면의 기준 시각 표시가 이것을 보여준다.
- 공급원 인터페이스가 데이터 종류별로 나뉘어 있어([시세 데이터 공급원](../design/market-data.md)) 공급원을 바꿔도 화면과 DB는 그대로다.
- 유료화·광고 도입은 국내 시세 공급원 교체를 함께 결정해야 하는 일이 된다.
