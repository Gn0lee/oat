## 종목 검색 결과

KIS 마스터(2026-11-20~21 자, kospi·kosdaq·nas·nys·ams)로 쟀다. 맥북, Node 26.

- 종목 수 16,889(국내 3,968, 미국 12,921). 파싱 40ms, 검색용 문자열 만들기 25ms, 힙 약 7.5MB.
- 검색은 전 종목을 훑는다(코드 일치 > 보유 종목 > 코드 앞부분 > 이름·초성 앞부분 > 영문명 앞부분 > 이름·초성 포함 > 영문명 포함, 같은 점수는 짧은 이름 먼저). 보유 종목은 가짜 세 개이고, 실제로는 내가 볼 수 있는 장부의 계좌가 보유한 종목이다.
- 국내 마스터에는 영문명이 없어서(스크립트에서 빈 값) 영문명 검색은 미국 종목에만 해당한다.
- 15개 질의 × 1,000회: 평균 1.1ms, p50 0.9ms, p99 1.7ms, 최대 수 ms~22ms(GC, 실행마다 다름). **맥북에서 요청 하나씩 잰 값**이고 미니 PC·동시 요청은 재지 않았다.

| 질의 | 첫 결과 |
|---|---|
| `삼성` | 삼성전자(005930, 보유) |
| `ㅅㅅㅈㅈ` | 삼성전자 |
| `005930` | 삼성전자 |
| `애플`·`aapl`·`apple` | 애플(AAPL) |
| `tiger` | TIGER 미국S&P500(360750, 보유) |
| `kodex200` | KODEX 200 |
| `삼성전자우` | 삼성전자우 |

→ 따로 색인을 만들 필요가 없다. 검색 시간보다 네트워크 왕복이 훨씬 길어서, 앱은 글자마다 약 150ms 늦춰 서버에 묻는다. KIS 미국 마스터에 한글 이름이 있어 "애플" 같은 한글 검색이 된다. 영문 브랜드를 초성으로 찾는 것(`ㅌㅇㄱ` → TIGER)은 안 된다.
