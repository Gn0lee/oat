## 1. 한 장 요약

| 항목 | 결정 |
|---|---|
| 서비스명 | **oat** (앱 표시 이름도 oat) |

| 스토어 이름 | `oat - 가족 가계부` 꼴(30자 안). 문구는 출시 준비 때 정한다 |

| 앱 아이콘·로고 | Pine 바탕에 귀리색 **"oat." 워드마크**. 마침표 자리에 낟알이 62°로 누워 있다(4절) |

## 2. 이름이 쓰이는 곳

| 쓰이는 곳 | 값 | 나중에 바꾸기 |
|---|---|---|
| 앱 표시 이름·스토어 이름 | oat | 쉬움 |
| 번들 ID | `day.oat` / `app.oatbook` | 불가 |
| 도메인 | API(`api.도메인`), Apple 로그인 콜백, 유니버설 링크, 랜딩, 인증 메일 발신 | 어려움(콘솔 등록·메일 평판) |
| 딥링크 스킴 | `oat://` | 앱 업데이트로 가능 |

커스텀 스킴은 다른 앱과 겹칠 수 있다(App Store에 OAT 이름의 앱이 여럿 있다). 그래서 로그인 복귀와 공유 링크는 유니버설 링크를 우선하고, 스킴은 보조로 둔다.

## 3. 색

### 3.1 라이트 토큰

| 토큰 | 값 | 비고 |
|---|---|---|
| primary | `#14573F` | Pine. 흰 라벨 대비 8.52 |
| primary-pressed | `#0E4431` | |
| primary-soft | `#E6F0EB` | 선택 배경, 배지 |
| background | `#F4F5F3` | 귀리색 바탕. Pine 텍스트 대비 7.79 |
| surface | `#FFFFFF` | row 묶음, 시트 |
| surface-alt | `#EFECEA` | Linen. 섹션 배경 차이 |
| text | `#191F28` | |
| 상승 / 하락 | `#F04452` / `#3182F6` | 숫자 전용, 그대로 유지 |

다크 값은 디자인 스펙에서 정한다. 원칙은 두 가지다. Pine은 다크에서 밝게 올린다. 상승·하락 색도 다크 바탕 대비를 맞춘다.

### 3.2 쓰는 곳과 쓰지 않는 곳

- **Pine을 쓰는 곳**: 주 버튼, 선택된 탭·세그먼트, 링크, 포커스, 진행률, 로고, 앱 아이콘.
- **Pine을 쓰지 않는 곳**: 금액·증감 숫자, 차트의 손익 계열, 큰 면적 배경. 해외 관례가 "상승=초록"이라 숫자에 쓰면 의미가 헷갈린다.
- **빨강·파랑은 숫자에만 쓴다.**
- **Ember 주황은 폐기한다.** indigo도 쓰지 않는다.

### 3.3 Ember를 버린 이유

- 상승 빨강 숫자 옆에 주황 버튼·탭이 붙으면, 따뜻한 색 두 개가 경쟁하고 의미가 헷갈린다.
- 흰 글씨 대비가 2.87이다. 4.5를 넘기려면 `#C2410C`까지 내려야 하는데, 그러면 벽돌색이 된다.

### 3.4 남은 메모

- 상승·하락 색은 흰 바탕 대비가 3.71이라, 작은 본문 크기로는 AA에 못 미친다. 금액 표시의 최소 크기·굵기는 통계 화면 구성과 모바일 입력 UX 원칙에서 정한다.
- Pine은 채도가 낮아 작은 면적에서 검정처럼 보일 수 있다. 아이콘과 선택 상태는 실기기에서 확인한다.

## 4. 앱 아이콘과 로고

원본: [`assets/oat-app-icon.svg`](assets/oat-app-icon.svg) (1024×1024, 모서리 없음. iOS가 둥근 모서리를 씌운다)

- **모양**: 원과 막대로 만든 소문자 "oat"이고, 마침표 자리에 귀리 낟알 하나가 62°로 누워 있다. 앱 아이콘과 앱 헤더·랜딩 로고에 같은 모양을 쓴다.
- **색**: Pine `#14573F` 바탕, 귀리색 `#EADFC8` 글자.
- **획**: o·a 링은 76, t의 세로획은 68이다. 직선은 곡선보다 굵어 보여서 t를 덜어 냈다. t는 꼭지가 있고 아래 끝이 오른쪽으로 휜다.
- **기존 아이콘은 폐기한다**: indigo 바탕에 흰 3D "O"와 빨강·파랑 화살표.

거친 시안과 버린 이유:

| 시안 | 버린 이유 |
|---|---|
| 낟알 하나, 이삭, 그릇 같은 심볼만 | 커피콩·잎, 친환경 앱, 샐러드 앱으로 읽힘 |
| t 꼭지를 낟알로, t 위에 낟알 | 촛불이나 악센트 부호(ť)로 읽힘 |
| o·a 구멍을 낟알 모양으로 | 세로로 찢어진 눈동자처럼 보여 무서움 |
| o·a 위 악센트 | o는 사과·복숭아, a는 스페인어 "á"로 읽힘 |
| 마침표를 세움(30° 안팎) | 쉼표 "oat,"로 읽힘 |

남은 위험: 마침표 낟알이 62°라 작은 크기에서는 쉼표 쪽으로 조금 기운다. 최종 내보내기(1024px와 각 크기) 전에 실기기 홈 화면에서 확인한다.

## 5. 정식 출시 준비로 넘기는 것

- 도메인 구매(oat.day 가격 확인)는 패스키·유니버설 링크를 검증하기 전, 그리고 첫 스토어 제출 전에 한다. 네이티브 Apple 로그인 PoC에는 필요 없다(ADR 0021).
- 상표 출원: 문자 "oat"·"오트"를 9·36·42류에, 로고는 따로. 출원 전에 변리사 선행조사를 받는다. 42류에 디자인업 "OAT" 출원(4020260186453)이 있다.
- 스토어 이름·부제·키워드 문구.
